# 校园失物招领

软件工程第二次结对作业：基于第一次作业中的校园失物招领设计，完成可在浏览器运行的校园寻物与招领平台。

## 功能

- 浏览寻物与招领信息，并按类型筛选。
- 发布寻物或招领信息；名称、地点、时间和联系方式为必填项。
- 按名称、类别、地点、描述或发布者搜索，并按类型和最近三天过滤。
- 查看详情与联系方式；点击“联系 TA”可复制联系方式，不支持剪贴板时直接显示。
- 查看“我的发布”和收藏；发布者将寻物标为“已找到”或招领标为“已归还”。
- 新发布信息、收藏和状态保存在本机浏览器的 `localStorage`，刷新后仍保留。

本项目为纯前端静态网页，不含账号、后端或跨设备同步。内置信息仅用于演示，不代表校园实时失物信息。

## 运行

### Chrome 直接打开

1. 从 GitHub 下载仓库 ZIP 并解压。
2. 使用 Google Chrome 打开根目录 `index.html`，页面会转到 `程序/index.html`。
3. 也可直接打开 `程序/index.html`。

如浏览器对本地文件存储限制较严，可在项目根目录运行 `python -m http.server 8000`，然后使用 Chrome 访问 <http://localhost:8000/>。项目不需要构建或依赖安装。

## 单元测试

安装 Node.js 后，在仓库根目录运行：

```bash
node --test 单元测试/lost-found.test.js
```

测试使用 Node.js 自带的 `node:test` 与 `node:assert/strict`，当前共 19 个用例，无需 npm 包。

简易教程：测试文件使用 `require('../js/lost-found.js')` 引入纯逻辑模块。`test('行为描述', ...)` 定义一个独立用例；`assert.equal` 比较标量，`assert.deepEqual` 比较对象/数组，`assert.match` 检查错误信息。为成功输入、边界值和非法输入分别编写用例，运行 `node --test` 后按失败测试名和断言差异定位问题。

## 数据与边界说明

- 首次运行显示 7 条内置示例数据；发布、收藏、解决状态存于当前浏览器。
- 必填项缺失时会说明原因，不会创建条目。
- “最近三天”依据实际发布时间过滤；未找到时页面显示空结果说明。
- 本项目没有登录系统，“我的发布”仅表示当前浏览器本地创建的信息。
- 图片上传、后台、实名认证、即时聊天和地图定位不在本次范围内。
- 本地保存异常会提示用户并保留当前界面状态；本地存储损坏时会提示并回退到示例数据。
